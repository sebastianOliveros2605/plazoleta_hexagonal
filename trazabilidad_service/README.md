# Trazabilidad Service

## Endpoints de consulta

Este servicio se enfoca en registro y consulta de trazabilidad.
El reporte de eficiencia se expone en `plazoleta-service`.

- `GET /trazabilidad/pedido/{idPedido}`
- `GET /trazabilidad/cliente/{idCliente}`
- `GET /trazabilidad/restaurante/{idRestaurante}`
